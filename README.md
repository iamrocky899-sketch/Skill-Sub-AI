# 🤖 Skill Sub AI

> **Your Personal Vocational AI Tutor**

Skill Sub AI is a premium AI-powered Android application designed for Class IX–XII vocational students. It combines Artificial Intelligence, personalized learning, offline-first architecture, and modern Android development to create an intelligent study companion.

---

# 🌟 Vision

To build the fastest, smartest, and most beautiful AI-powered vocational learning platform that helps students learn through conversation, books, images, voice, and interactive quizzes.

---

# 🎯 Mission

Provide every vocational student with a personal AI tutor that is available anytime, anywhere.

---

# 📏 Development Rules

- Keep the UI unique.
- Do not imitate other applications.
- Performance comes before visual effects.
- Prefer local storage whenever possible.
- Follow clean architecture.
- Write scalable code.
- Never expose API keys.
- Optimize every screen.
- Every feature must improve learning.

# ❤️ Core Principle

Skill Sub AI is **not a general chatbot**.

It is an intelligent vocational learning platform that provides personalized education through AI while remaining fast, secure, and student-friendly.

Every feature should help students learn more effectively.
